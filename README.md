# Rice Variety Classifier  

**Rice Variety Classifier** is an advanced application written in C# that enables the categorization of rice varieties based on image analysis of grains. The application utilizes modern thresholding algorithms, segmentation techniques, and the Otsu Algorithm, along with various mathematical methods, to ensure accuracy and speed in identification.  

## Features  

### Application Modes  

1. **Application Improvement Mode**  
   - The user can upload rice images into the application.  
   - The application analyzes the uploaded images, identifies rice varieties, and saves the results.  
   - The saved data is used to continuously improve classification accuracy and enhance fast recognition of varieties in the future.  

2. **Quick Identification Mode**  
   - The user uploads an image of a rice grain.  
   - The application processes the image, detects rice grains, and returns the identified variety name to the user.  

## Technologies  

- **Programming Language:** C#  
- **Graphical User Interface:** Windows Forms  
- **Algorithms:** Thresholding, Segmentation, Otsu Algorithm, Mathematical Methods  

## System Requirements  

- **Operating System:** Windows 7 or later  
- **.NET Framework:** 4.7.2 or later  
- **Processor:** Intel Core i3 or better  
- **RAM:** 4 GB or more  
- **Disk Space:** 100 MB for installation  

## Installation  

1. Download the latest version of the application from the [GitHub repository](https://github.com/OG-YODA/Rice-Grains-Categorization).  
2. Extract the downloaded archive.  
3. Run the `setup.exe` installer and follow the installation instructions.  

## Usage  

1. Launch the application.  
2. Select the operating mode (Application Improvement or Quick Identification).  
3. Upload rice images.  
4. Receive analysis results.
